# Kerangka Laporan BankSampahKu

Isi nama pemilik bab setelah pembagian anggota disepakati. Jangan masukkan data contoh sebagai fakta.

| Bab | Isi | Pemilik |
|---|---|---|
| 1. Pendahuluan | Latar belakang, masalah, tujuan, batasan | Belum ditentukan |
| 2. Analisis kebutuhan | Pengguna, kebutuhan, ruang lingkup halaman | Belum ditentukan |
| 3. Perancangan | Alur navigasi, rancangan tampilan, responsivitas | Belum ditentukan |
| 4. Implementasi | HTML, CSS, serta fitur bonus JavaScript | Belum ditentukan |
| 5. Pengujian | Pemeriksaan HTML/CSS, browser, tautan, responsivitas | Belum ditentukan |
| 6. Kesimpulan | Hasil, keterbatasan, saran pengembangan | Belum ditentukan |

## Sumber aset dan data

Catat sumber, pemilik, lisensi atau izin penggunaan gambar, ikon, teks, serta data harga dan kontak.
