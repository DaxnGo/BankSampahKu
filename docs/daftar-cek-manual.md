# Daftar Cek Manual

Buka di browser sungguhan.

## Tampilan
- [ ] Beranda 375 px dan 1280 px: tanpa gulir horizontal.
- [ ] Buku tabungan dan stempel status terbaca jelas.
- [ ] Nav ponsel: merek dan tombol tema di baris atas, nav bisa digeser.
- [ ] Kontak 375 px: jam operasional, peta, galeri tampil.
- [ ] Login 375 px: form dulu, penjelasan kemudian.
- [ ] Mode gelap terbaca, tanpa latar krem.

## Interaksi
- [ ] Tombol tema berganti ikon dan tersimpan setelah muat ulang.
- [ ] Fokus keyboard jelas pada tautan, tombol, input.
- [ ] Tautan peta, telepon, wa.me berfungsi.
- [ ] Form Kontak: validasi kosong dan pesan berhasil.

## Akun dan data
- [ ] Masuk sebagai warga: saldo, berat, riwayat sesuai sesi.
- [ ] Masuk sebagai petugas: form setoran ada di nav.
- [ ] Tambah setoran, lalu cek angka dashboard berubah.
- [ ] Kembalikan data contoh awal: angka kembali semula.

## Lainnya
- [ ] Aktifkan kurangi gerak: animasi tidak mengganggu.
- [ ] Perbesar 200 persen: teks tidak terpotong.
- [ ] Periksa konsol: tanpa galat JS atau jaringan.
