# BankSampahKu

Website edukasi bank sampah warga dengan empat halaman: Beranda, Cara Memilah, Harga Sampah, dan Kontak.

## Tujuan

BankSampahKu membantu warga memahami cara memilah sampah dan mengenal layanan bank sampah. Data harga, alamat, nomor telepon, dan jam buka di website hanya contoh sampai tim menggantinya dengan data yang sudah disetujui.

## Tangkapan layar

> Tambahkan tangkapan layar halaman utama di sini setelah tampilan final tersedia.

## Demo

> Tautan GitHub Pages akan ditambahkan setelah repo dibuat dan Pages diaktifkan.

## Fitur utama

### Wajib (HTML dan CSS)

- Empat halaman yang saling terhubung.
- Informasi edukasi pemilahan dan harga sampah.
- Tampilan responsif dan dapat dibaca tanpa JavaScript.

### Bonus (JavaScript)

- Kalkulator perkiraan saldo.
- Fitur tambahan hanya sebagai peningkatan; konten inti tetap tersedia tanpa JavaScript.

## Teknologi

- HTML
- CSS
- JavaScript untuk fitur bonus

## Menjalankan di komputer

1. Unduh atau clone repo setelah alamat repo tersedia.
2. Buka `index.html` di browser.
3. Tidak perlu server atau instalasi paket untuk melihat halaman statis.
